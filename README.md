Project Wingman PvP - установка
================================

1. Steam -> правый клик по Project Wingman -> Управление -> Просмотреть локальные файлы.
2. Откройте папку ProjectWingman\Binaries\Win64
   (там лежит ProjectWingman-Win64-Shipping.exe).
3. Скопируйте туда ВСЁ из этого архива, чтобы получилось:
      Win64\dwmapi.dll
      Win64\ue4ss\
4. Запустите игру через Steam.

Игра вдвоём (вы друзья в Steam, мод из одного и того же архива):
  - хост: кнопка PvP на главном экране игры -> "Host game" -> "Invite friend (Steam)" -> выбрать друга;
  - друг: принять приглашение в Steam. Мод подключится сам.
  Открывать порты не нужно.

Удаление: удалите Win64\dwmapi.dll и папку Win64\ue4ss.

Если антивирус удалил dwmapi.dll - добавьте его в исключения
